
# 🌌 AstroBuddy — Your Personal Night Sky Companion

**Explore the cosmos. Discover celestial wonders. Keep looking up.**

AstroBuddy is an interactive, space-themed web application designed to make astronomy accessible, engaging, and enjoyable. From exploring planets and galaxies to planning your next stargazing adventure, AstroBuddy brings the wonders of the universe to your browser through a beautiful and responsive interface.

Built with HTML, CSS, and JavaScript, AstroBuddy combines astronomy exploration, educational content, and interactive tools in one cosmic experience.

## ✨ Features

### 🌠 Cosmic Dashboard
- Beautiful space-inspired interface with a dark cosmic theme.
- Current date display.
- Astronomy tips and stargazing suggestions.
- Featured guides to celestial objects, including Jupiter and the Moon.

### 🪐 Cosmic Explorer
- Explore planets, galaxies, and deep-space objects.
- Search celestial objects by name or category.
- Interactive information dialogs with descriptions and astronomy facts.
- Discover Saturn, Mars, the Andromeda Galaxy, and nebulae.

### 🔭 Stargazing Planner
- Choose a date for your next observation session.
- Enter your city or observing location.
- Select your observing equipment.
- Choose observation targets, from the Moon and planets to galaxies and constellations.
- Generate a personalized observation checklist with practical stargazing tips.

### 🤖 Astro AI Assistant
- Interactive astronomy question-and-answer interface.
- Suggested questions for quick exploration.
- Built-in astronomy responses covering topics such as black holes, Mars, stars, galaxies, and meteor showers.
- A foundation for future integration with open-weight AI models.

### 🎨 Cosmic UI and Responsive Design
- Dark theme with purple and cyan accents.
- Planetary illustrations and orbital effects created with CSS.
- Responsive layouts for desktop, tablet, and mobile devices.
- Interactive navigation, buttons, search, and information dialogs.

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Page structure and semantic content |
| CSS3 | Styling, layouts, animations, and responsive design |
| JavaScript | Interactions, search, observation planning, and astronomy assistant |
| Google Fonts | Space Grotesk and DM Sans typography |

AstroBuddy uses vanilla JavaScript and requires no frontend framework or package installation.

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- Visual Studio Code or another code editor.
- An internet connection for Google Fonts.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/AstroBuddy.git
   ```

2. Navigate to the project directory:

   ```bash
   cd AstroBuddy
   ```

3. Open `index.html` in your browser.

   Alternatively, open the folder in Visual Studio Code and launch `index.html` using the Live Server extension.

No build tools or dependencies are required.
